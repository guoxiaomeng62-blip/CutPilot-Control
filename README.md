# CutPilot 智能极片搬运冲切平台

本仓库保存 PLC 自动循环控制的 ST（Structured Text）核心逻辑模板。

## 文件

- `plc/FB_CutPilot.st`：视觉定位、送料、冲切、逐穴检测、吸取、放料与返回。

## 接入条件

该程序为设计示例，尚未经过指定 PLC 编译或实机验证。需要结合实际 PLC、I/O、气动阀型和运动控制功能块适配。

- XExecute/XTarget/XDone 接入定位控制；完成信号必须属于当前任务。
- 视觉触发应通过任务编号或握手协议防止读取旧结果。
- ReleaseOK 需要实际放料确认，不能仅以真空消失判断。
- 急停、门禁、防坠和故障期间真空保持由独立硬件及安全回路实现。
- Stop 禁止新循环；当前循环结束后等待。立即停止由安全回路处理。
- 工步超时暂设10秒，需按实际动作分别整定。
- 单次循环加工一件料片的五个穴位，每次需重新启动并确认上料。

当前仅有设计代码，未声明实测节拍、精度或可靠性。
